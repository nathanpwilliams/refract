Refract — one course, written once; many audiences, each one earned

Corporate training ships one generic course because nobody can afford to author four. Refract is an audience-adaptive course platform: an author writes one canonical course, and a pipeline refracts it into audience-specific versions — reshaping scenarios, worked examples and emphasis for a given role — while holding the things that must not drift byte-identical.

Courses are structured content blocks in Postgres rather than documents, which is what makes per-block adaptation and per-block integrity proofs possible. Adaptation runs through a machine warranty instead of a human sign-off: blocks the planner does not select never reach a model at all, a deterministic check suite proves what it covers with perfect recall, two different models verify independently, and anything that fails is reverted to the canonical text in code. Published versions render in a web player and export as SCORM 1.2 packages for any corporate LMS.

The two pages below are the real output of one run, built from what the database stored: 10 of 38 blocks were selected for adaptation, 9 of 10 adaptations survived the checks, and the version published with no human in the loop.

This is a work in progress, and the course content is a sample. What you can read here is Module 1 — three lessons — of a planned four-module course, refracted for a “managers” audience profile. The platform is under active development; this demo is a snapshot, not a product.

How it is built

Python 3.12 and FastAPI at the root, Next.js 16 in web/, Postgres via Supabase, SCORM 1.2 generated server-side. The adaptation pipeline, the check suite and the SCORM exporter are the parts worth reading; each was built from a written brief in docs/, and the briefs record the design decisions and the acceptance criteria rather than just the outcome.
